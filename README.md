# Mailing Service (Сервис рассылок)

## Описание

Данный проект — сервис управления Email-рассылками.  
Он позволяет пользователям создавать, редактировать и отправлять рассылки своим клиентам, а также отслеживать статистику успешных и неуспешных попыток доставки писем.

## Основной Функционал

### 1. Управление получателями
- Добавление, просмотр, редактирование и удаление получателей рассылки.
- **Модель "Получатель"**:  
  - Email (уникальный)
  - Ф.И.О.
  - Комментарий

### 2. Управление сообщениями
- CRUD для сообщений (тема письма, текст письма).

### 3. Управление рассылками
- CRUD для рассылок.
- **Статусы рассылки**:
  - Создана: рассылка создана, но ещё не отправлялась.
  - Запущена: рассылка активна и была отправлена хотя бы один раз.
  - Завершена: период отправки завершён.
- У рассылки:
  - Дата и время первой/последней отправки
  - Статус
  - Сообщение (связь с моделью "Сообщение")
  - Получатели (многие-ко-многим с получателями)

### 4. Отправка рассылок
- Возможность вручную запускать рассылки из интерфейса и через командную строку (manage.py).

### 5. Учёт попыток отправки
- Для каждой попытки отправки сохраняются:
  - Дата/время попытки
  - Статус (успешно / не успешно)
  - Ответ почтового сервера
  - Связь с рассылкой

### 6. Главная страница
- Количество всех рассылок
- Количество активных рассылок (статус "Запущена")
- Количество уникальных получателей

---

## Расширения (Часть 2)

### 7. Регистрация и аутентификация
- Регистрация с подтверждением email
- Вход/выход
- Восстановление пароля (reset password)

### 8. Статистика
- Для пользователей показывается статистика по своим рассылкам: количество успешных/неуспешных попыток, количество сообщений.

### 9. Роли и ограничение доступа
- **Пользователь:**
  - Управляет только своими рассылками и клиентами.
  - Просматривает свою статистику.
- **Менеджер:**
  - Видит все рассылки и клиентов, не может изменять/удалять чужие рассылки и клиентов.
  - Может блокировать пользователей сервиса и отключать рассылки.
  - Просмотр списка пользователей.

### 10. Кеширование
- Настроено серверное и клиентское кеширование для повышения производительности.

---

## Модели

- **Client** (Получатель): email, ФИО, комментарий
- **Message** (Сообщение): тема, тело письма
- **Mailing** (Рассылка): первая/последняя отправка, статус, сообщение, получатели
- **MailingAttempt** (Попытка рассылки): дата/статус/ответ сервера, связь с рассылкой
- **User** (Пользователь): регистрация, авторизация, email-подтверждение, сброс пароля

## Установка и запуск

1. **Клонируйте репозиторий:**
   git clone <this_repo_url>
   cd mailing-service


2. **Создайте виртуальное окружение и активируйте его:**
python -m venv .venv
  source .venv/bin/activate


3. **Установите зависимости:**
pip install -r requirements.txt


4. **Выполните миграции:**
python manage.py makemigrations
   python manage.py migrate

5. **Создайте суперпользователя (администратора):**
python manage.py createsuperuser


6. **Запустите сервер:**
python manage.py runserver


7. **(Опционально) Настройте переменные окружения (email, кеширование и пр.)**

## API

- Документация к API доступна на `/swagger/` или `/redoc/` (если настроено).
- Базовые endpoint'ы:  
  - `/api/clients/` — получение/редактирование/удаление получателей  
  - `/api/messages/` — CRUD сообщений  
  - `/api/mailings/` — управление рассылками  
  - `/api/attempts/` — попытки рассылки  
  - `/api/auth/` — регистрация, вход, восстановление пароля  
  - `/api/users/` — просмотр пользователей (для менеджеров)

## Тестирование и запуск рассылок

- Рассылки можно запускать вручную через интерфейс или командой:
python manage.py send_mailing <mailing_id>
